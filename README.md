# 2023 Tutorial (중간고사 범위, C/C++)

2023년 튜토리얼 수업의 중간고사(MT) 범위 C/C++ 실습 코드입니다. 파일 앞의 번호는 예제 번호입니다.

## 주요 내용

| 번호 | 주제 |
| --- | --- |
| 001 ~ 003 | 출력 기초 |
| 032 ~ 036 | 문자열: 출력, `strcat`, `strlen`, `strcpy`, `strcmp` |
| 038 ~ 043 | 포인터: 포인터 기초, 배열 포인터, 2차원 배열 포인터, 포인터 배열, 2차원 문자열 배열 |
| 050 ~ 054 | 구조체: 사각형(거리·넓이), 학생 정보 |

## 실행 방법

```bash
g++ 040_arrayPointer.cpp -o arrayPointer
./arrayPointer
```
